# Hybrid RAG PR #7 리뷰 반영 설계

## 목적

PR #7의 미해결 리뷰 9건을 해결해 초기 설정 실패, corpus 경계 누락, chunk 처리 오류와 측정·문서 불일치를 제거한다.

## 설계

- index 생성은 모델 다운로드를 허용하되 Hook 런타임의 모델 로딩은 로컬 cache 전용으로 유지한다.
- 항상 사용할 수 있는 Python 래퍼가 `.venv` 존재를 확인한 뒤 RAG 실행기를 호출한다. runtime이 없으면 빈 출력과 종료 코드 0을 반환한다.
- corpus loader는 실행 근거에서 제외된 디렉터리와 심볼릭 링크를 거부한다.
- chunker는 긴 문단을 문자 경계로 분할하고, context formatter는 랭킹 사이에 다른 문서가 있어도 문서·줄 범위가 인접한 결과를 병합한다.
- 최종 manifest로 index와 평가를 다시 만들고, 검색 측정과 별도로 Hook 프로세스를 매 요청 실행해 실제 요청 지연시간을 기록한다.
- 현재 운영 문서는 Stop Hook과 토큰 요약이 더 이상 생성되지 않는다는 사실로 갱신한다.

## 검증

각 결함은 실제 입출력 또는 Hook 실행 결과를 검증하는 실패 테스트부터 추가한다. 전체 RAG·Hook 테스트, 최종 corpus index 생성, 평가와 실제 Hook 지연시간 측정을 다시 실행한다.
